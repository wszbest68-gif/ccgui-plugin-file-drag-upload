# 文件拖拽上传插件

> 为 CC GUI 提供完整的文件拖拽、预览和管理功能

## ✨ 功能

- 🎯 拖拽文件到聊天窗口，显示遮罩提示
- 📋 文件路径自动插入到输入框（@路径格式）
- 👀 文件管理面板，查看所有已添加的文件
- ✏️ 支持删除、重新排序、一键清空
- 💾 自动保存，重启不丢失

## 🚀 安装

1. 打开 CC GUI
2. 点击左侧边栏「插件」
3. 点击「从本地目录安装」
4. 选择目录：`C:\Users\wszbe\ccgui-plugins\file-drag-upload\`
5. 安装完成，立即生效

## 🎮 使用

### 拖拽上传
1. 从 Windows Explorer 选择文件
2. 拖拽到 CC GUI 聊天窗口
3. 看到遮罩提示后释放
4. 文件路径自动插入输入框

### 文件管理
1. 点击左侧「📁 文件」标签页
2. 查看所有已添加的文件
3. 使用 ↑↓ 调整顺序
4. 点击 ✕ 删除文件
5. 点击「清空」删除所有

## 🔒 权限说明

- `events`: 监听拖拽事件
- `storage`: 保存文件列表
- `composer:draft`: 插入路径到输入框
- `ui:panel-tab`: 显示文件管理面板
